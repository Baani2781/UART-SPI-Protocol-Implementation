# UART & SPI Communication Protocols | Verilog HDL

Designed and implemented UART and SPI communication protocols using **Verilog HDL** in **Xilinx Vivado**. The project includes RTL design, simulation, and functional verification of serial communication modules.

## Features
- UART Transmitter & Receiver with configurable baud rate
- SPI Master & Slave for full-duplex communication
- RTL simulation, testbenches, and waveform analysis using Vivado Simulator

## Tools
- Verilog HDL
- Xilinx Vivado
- Vivado Simulator
